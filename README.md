## 📌 Project Overview  
This **ATM Machine Simulation** is built in **Python** as part of the **Python Developer Internship** at **OctaNet Services Pvt Ltd**. It provides users with an **interactive and secure** experience to perform various banking functions, such as:  

- Account balance inquiry  
- Cash withdrawal  
- Cash deposit  
- PIN change  
- Transaction history  

This project implements **modern UI enhancements** using:  

- ✅ **Colorama** for **color-coded text output** to improve readability.  
- ✅ **Tabulate** for **table formatting** to display information neatly.

## ✨ Features  
✔️ **Account Balance Inquiry** – Check the available balance in a structured table format.  
✔️ **Cash Withdrawal** – Withdraw money with validation for insufficient balance.  
✔️ **Cash Deposit** – Deposit money securely into the account.  
✔️ **PIN Change** – Update the ATM PIN with validation.  
✔️ **Transaction History** – Track deposits and withdrawals.  
✔️ **Improved UI** – Uses colors and tables for a better experience.
